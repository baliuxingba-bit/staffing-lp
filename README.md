# staffing-lp

人手不足の企業向け、単発・短期の人員派遣サービスのランディングページ（静的HTML/CSS/JS、フレームワーク不使用）。

## プレビュー方法

`index.html` をブラウザで直接開くだけで確認できます。ビルドツールは不要です。

## 埋めるべきプレースホルダー（《 》【 】で囲まれた箇所）

- `《事業名》` … 会社名・ブランド名が決まったら、全ファイルを検索して一括置換してください（index.html / footer / title タグなど）。
- `【電話番号を入力】` … hero と contact セクションの2箇所。
- `【対応エリアを入力】` `【料金体系の説明を入力】` … FAQ セクション。
- `【送信先メールアドレスを入力】` … contact フォームの action URL（[FormSubmit](https://formsubmit.co/) を使用。初回送信時に確認メールが届くので、そのメールアドレスでリンクをクリックして有効化する必要があります）。
- `【運営会社名を入力】` `【住所を入力】` `【許可番号を入力】` … フッター。

## 法令面の確認（重要）

外国人材を含めて「派遣」として人を送り込む場合、日本では労働者派遣事業の許可（労働者派遣法）が必要です。フッターに許可番号欄を仮で用意していますが、実際にこの形態で事業を行ってよいか（労働者派遣か、請負か、紹介か）は、公開前に一度専門家（社労士・行政書士等）に確認することを強く推奨します。

## デプロイ（無料で公開する場合の例）

- [Vercel](https://vercel.com) や [Netlify](https://www.netlify.com) にこのフォルダをそのままドラッグ&ドロップ、または GitHub 連携でデプロイ可能。
- 独自ドメインを使う場合は、デプロイ後にドメイン設定を追加する。
